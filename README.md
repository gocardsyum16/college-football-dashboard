# SEC & Big Ten College Football Analytics Dashboard

## Project Overview
This project is an MVP analytics dashboard built with Dash and connected to a Supabase PostgreSQL database. The dashboard visualizes SEC and Big Ten college football team performance using data extracted from the CollegeFootballData API.

## Features
- Live connection to PostgreSQL through Supabase
- Interactive conference filter
- KPI cards for total teams and average win percentage
- Bar chart showing wins by team
- Scatter plot showing wins vs. losses
- Analytics-ready dataset created through a Python ETL pipeline

## Technologies Used
- Python
- Dash
- Plotly
- Pandas
- SQLAlchemy
- Supabase PostgreSQL
- CollegeFootballData API
